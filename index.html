Jarvis Newsletter Reader

Personal newsletter reading and analysis

Jarvis Newsletter Reader is a private, single-user application for reviewing selected finance newsletters in its operator’s Gmail account. It supports personal understanding of newsletter material and is being developed to support private summaries and podcasts.

Current operation: supervised newsletter previews only. Automated newsletter collection and daily podcast production are not active.

What the reader does

The reader checks the authorised mailbox identity, screens message metadata, and reads selected newsletter text. Its application controls restrict processing to a configured newsletter label and an approved sender list, with limits on message age and the number of messages inspected.

Gmail permission and limits

The application requests only Gmail read-only access. This Google permission is mailbox-wide: the label and sender restrictions are application controls, not restrictions enforced by Google’s permission grant.

The reader does not send, edit or delete email, change labels or filters, retrieve whole threads, or open newsletter links, attachments or remote images.

Privacy and documentation

Selected newsletter content can enter Jarvis’s configured AI processing and normal tool/session records. The Privacy Policy describes the data handling.

This website provides public application documentation only. It does not run the reader, offer public registration or sign-in, or provide access to a mailbox.
